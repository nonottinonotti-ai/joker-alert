# JOKER抗争ボイスアラート：利用者向け公開版

このフォルダだけを静的サイトとして公開してください。利用者はSTART / PAUSE / RESUME / RESETと試聴だけ操作できます。設定を変更する画面・共有設定への書き込みAPIはありません。

## 配布・更新

1. 管理者は別配布の `joker-admin/index.html` を手元のブラウザで開きます。
2. 時刻・名称・MP3・ON/OFFを編集し、「音声・設定を書き出す」を押します。
3. ダウンロードされた `shared-config.json` を、このフォルダの同名ファイルに上書きします。
4. この公開フォルダを再アップロードします。公開作業はホスティングの管理権限で行います。
5. 利用者は抗争開始前にページを再読み込みします。

音声もJSONに含むため、更新はこの1ファイルで完結します。利用者ごとの古いlocalStorage設定は使いません。タイマー進行中に設定が変わることはありません。開いたままの画面へ自動配信する方式ではなく、再読み込みで反映します。

初回は5・10・15・20・25分の加勢判定10秒前のプリセットです。MP3は未登録です。全員で同じ音声を使うには、管理者側でMP3を登録して配布してください。未登録時の読み上げ音声は端末ごとに異なり、日本語音声がない端末では再生できません。

## 起動

JSONを読み込むので、index.htmlの直接ダブルクリックではなくHTTPサーバーから開きます。Pythonがある場合、このフォルダで実行してください。

```sh
python -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。静的ホスティングでもビルドは不要です。

## 公開ファイル

- index.html：利用者用画面
- styles.css：レスポンシブなダークUI
- assets/joker-header.png：ヘッダー画像
- shared-config.json：管理者が配布する設定・MP3
- js/config.js：配布データの形式検証
- js/viewer.js：読み込み・表示・タイマー操作
- js/timer.js：開始時刻との差分、停止再開、発動履歴
- js/audio.js：MP3と端末読み上げの再生

`joker-admin` は公開対象に含めないでください。公開用ZIPにも管理者エディターは含めていません。

## 権限・仕様

管理者がアップロード権限を持ち、利用者には共有設定を更新する手段を提供しません。管理者エディター自体はログイン式の管理サイトではなく、管理者の手元でファイルを書き出す道具です。ブラウザ内の表示を利用者自身が改変しても、サーバーや他の利用者の設定には影響しません。

URLを知る人がアクセスできます。URLの秘密性を保証するアクセス制限はありません。音声・設定は閲覧者がダウンロードできます。

配布設定を読み込めない場合は、別の設定で勝手に開始せずSTARTを無効にします。RESETでは同じ配布設定を維持します。再読み込みでは経過時間と発動履歴が初期化されます。

画面ロック・バックグラウンド・端末スリープ中の通知はブラウザ/OSの制限を受けます。画面を開いたまま使い、対象端末で試聴してください。

現時点で外部への公開は行っていません。PWA化する場合は、共有JSONを古いキャッシュから返さない設計にしてください。
